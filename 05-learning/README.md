# Learning hub — Reto AI-First Fase 1

Base reusable de aprendizaje, decisiones propuestas, plantillas y trazabilidad del Track DEV.

## Reglas

- El código ejecutable vive únicamente en `06-code/`.
- Ningún documento de esta carpeta demuestra por sí solo que una funcionalidad exista.
- Las decisiones heredadas se consideran propuestas hasta aprobación explícita.
- La ejecución inicial se limita a HU-001, HU-002 y HU-003.
- Todo cambio aprobado actualiza `00-traceability/change-log.md`.
- No se almacenan secretos, tokens, contraseñas ni datos personales reales.

## Estructura

- `00-traceability/`: guardián y bitácora técnica nueva.
- `01-planning/`: gobierno, stack propuesto y plantillas de ejecución.
- `02-architecture/`: arquitectura propuesta y límites entre capas.
- `03-requirements/`: entendimiento, HU iniciales y criterios.
- `04-code/`: guías y referencias no ejecutables.
- `skills.md`: skills de apoyo instaladas fuera del repositorio.
