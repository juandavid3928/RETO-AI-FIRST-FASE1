# Buenas prácticas AI-First

- Trabajar una historia aprobada a la vez.
- Usar contratos observables y criterios verificables.
- Aplicar RED → GREEN → REFACTOR cuando comience implementación.
- Mantener nombres de archivos en inglés y kebab-case para documentación.
- Mantener nombres de código coherentes con el lenguaje.
- No hardcodear secretos ni datos productivos.
- No presentar salidas esperadas como ejecutadas.
- Manejar loading, empty, error y success.
- Normalizar datos externos detrás de un adaptador.
- Registrar solo evidencia comprobada.
