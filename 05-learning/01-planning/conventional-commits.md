# Conventional Commits

Formato, solo cuando el usuario autorice commit:

```text
<type>(<scope>): <description>
```

Ejemplos:

```text
feat(HU-001): add user registration endpoint
test(HU-002): cover invalid login credentials
docs(onboarding): record approved repository reset
```

Tipos: `feat`, `fix`, `test`, `docs`, `refactor`, `build`, `ci`, `chore`, `revert`.

No ejecutar commit ni push por iniciativa propia.
