# Entendimiento del proyecto

## Problema

Contratistas y proveedores necesitan encontrar convocatorias públicas colombianas mediante una experiencia unificada y comprensible.

## Producto esperado

Portal web con autenticación, backend REST, persistencia e integración con SECOP II/datos.gov.co.

## Alcance inicial aprobado para definición

- Registro.
- Login/JWT.
- Búsqueda SECOP desde backend.

## Supuestos pendientes

- Campos exactos del usuario.
- Dataset y campos SECOP definitivos.
- Modelo relacional mínimo.
- Política de cache.
- Alcance posterior de bookmarks y búsquedas guardadas.
